# ASCURE Mobile

Expo React Native technician app for the ASCURE field workflow MVP.

## Run

```bash
pnpm start
```

## API base URL

The app defaults to:

- Android emulator: `http://10.0.2.2:3000/api/v1`
- Other platforms: `http://localhost:3000/api/v1`

Override with:

```bash
EXPO_PUBLIC_API_BASE_URL=http://your-host:3000/api/v1
```
